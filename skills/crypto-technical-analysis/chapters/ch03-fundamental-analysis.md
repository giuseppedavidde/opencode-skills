# Chapter 3: Fundamental Analysis

## Core Idea
Fundamental analysis assesses the intrinsic value of a cryptocurrency through valuation techniques. Coins have an intrinsic value that should eventually be reflected in price; prices below true value = undervalued (buy), above = overvalued (sell).

## Frameworks Introduced
- **Top-Down Approach**: Economy → Sector → Individual asset (funnel down)
- **Bottom-Up Approach**: Individual asset first, then broader context
- **Five-Metric Framework**: On-chain | Project | Sentiment | Utility | Relative Value
- **TA + FA Combo**: FA for what to buy, TA for when to enter/exit

## Key Concepts
- **On-Chain Metrics**: Exchange deposits, miner flows, transaction value, active addresses, hash rate, fees
- **Project Metrics**: Team quality, whitepaper credibility, event calendar, competitive landscape
- **Sentiment**: Social perception alters perceived value; tools like Fear & Greed Index, Santiment
- **Utility**: Real-world use cases separate sustainable projects from speculation
- **Relative Value**: Compare similar projects to find undervalued assets

## Crypto-Specific Considerations
- On-chain metrics are unique to crypto (no equivalent in stocks); better for short-to-mid-term
- FA correctness increases over time while TA decreases—TA for short-term, FA for long-term
- Crypto FA is more speculative than stock FA due to subjective valuation
- Team evaluation is critical but harder: pseudonymous teams, unregulated space
- Whitepapers can be marketing documents, not technical specifications

## Key Takeaways
- Best strategies combine FA (what to buy) + TA (when to buy/sell)
- Intrinsic value is subjective; different analysts reach different conclusions
- On-chain metrics provide crypto-specific fundamental data unavailable in traditional markets
