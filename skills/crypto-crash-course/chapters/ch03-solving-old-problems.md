# Chapter 3: Solving Old Problems — Speed, Cost, Trust, Security

## Core Idea
Cryptocurrencies were designed specifically to fix four major problems with traditional banking: slow transaction speeds, high fees, lack of transparency/trust, and security vulnerabilities. Each is solved by the decentralized, code-driven nature of crypto networks.

## Frameworks Introduced
- **Four-Pillar Problem/Solution Matrix**:
  1. **Speed** → Automated code-driven verification vs. human bureaucracy
  2. **Price/Cost** → Peer-to-peer collaboration eliminates middleman fees
  3. **Trust** → Mathematical objectivity replaces fallible human bankers
  4. **Security** → Cryptographic protection + multi-node verification vs. centralized databases

## Key Concepts
- **Speed**: Banks have layers of bureaucracy; crypto transactions verify automatically via code. Network-wide votes on protocol changes happen faster than industry-wide bank reforms.
- **Cost**: Banks employ humans in physical offices — you pay for that overhead. In crypto, every user's computer contributes to verification, splitting the workload and cost.
- **Trust**: Banks are opaque (privacy laws prevent transparency). Crypto transactions are recorded on a public ledger viewable by anyone. Code is objective; humans can be corrupted.
- **Security**: Cryptography protects the system. Every transaction is verified by multiple independent nodes. Each transaction is an independent entity — hacking one doesn't compromise others.
- **Immutability**: Once a block is added, altering it requires controlling >50% of network power, which is prohibitively expensive

## Anti-patterns
- Assuming crypto has zero fees — transaction fees still go to miners (though lower than bank fees)
- Believing crypto is 100% unhackable — exchanges and hot wallets can be compromised
- Thinking all banks are equally corrupt — the argument is about systemic risk, not individual institutions

## Key Takeaways
- Crypto eliminates bureaucratic delays by automating verification through code
- Removing middlemen drastically reduces transaction costs
- Public ledgers replace "trust us" with "verify it yourself"
- Cryptographic security makes fraud exponentially harder than in traditional banking
