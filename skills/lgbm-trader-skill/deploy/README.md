# Prediction Monitor — Automation Templates
# These are COMMENTED templates. Do NOT install — adapt to your system.

## Cron approach (simplest)
#
# Daily at 08:00 UTC: backfill new predictions, print report
#
# 0 8 * * * cd ~/.config/opencode/skills/lgbm-trader-skill && python scripts/backfill_prediction_log.py --predictions /path/to/predictions.csv --dedupe --cutoff 2024-06-30 >> /tmp/prediction_monitor.log 2>&1
# 0 8 * * * cd ~/.config/opencode/skills/lgbm-trader-skill && python scripts/performance_report.py --log ~/.config/opencode/predictions/prediction_log.jsonl --min-required 20 >> /tmp/prediction_monitor.log 2>&1

## Systemd approach (more robust)
#
# Files: deploy/prediction_monitor.service + deploy/prediction_monitor.timer
# Install: cp deploy/*.{service,timer} ~/.config/systemd/user/
#          systemctl --user daemon-reload
#          systemctl --user enable --now prediction_monitor.timer
#
# Notes:
# - The service runs the performance report script
# - Backfill should be run separately before enabling the service
# - Adjust paths to match your environment
# - The timer runs daily at 08:00 UTC

## Prerequisites
#
# 1. Export CSV must exist (generated by scripts/export_predictions.py)
# 2. Prediction log must be backfilled first:
#      python scripts/backfill_prediction_log.py --predictions <CSV> --dedupe
# 3. Python venv must be activated or use full path to python binary
