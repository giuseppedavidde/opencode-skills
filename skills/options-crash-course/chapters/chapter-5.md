# Chapter 5: The Technical Analysis

## Core Idea
Two analysis methods serve different timeframes and purposes. Technical analysis studies price history to predict short-term movement. Fundamental analysis studies economic reality to predict long-term value. The winning approach: start with technical analysis for quick wins and confidence, then layer in fundamental analysis for sustainable success.

## Frameworks Introduced
- **Technical Analysis Framework** — All market information is reflected in price. Study past prices, trends, and patterns to forecast future movement. Subjective in interpretation, textbook in method. Best for short-term trades (days to weeks).
- **Fundamental Analysis Framework** — Study the economy, employment, trade balances, and national policies. Objective and factual. Best for long-term positioning (months to years).
- **Progressive Layering** — Use technical analysis first (builds confidence, fast feedback), then gradually add fundamental analysis as account grows.

## Key Concepts
- **Price Reflects All Information**: Core assumption of technical analysis — everything affecting an asset eventually shows up in its price
- **Trend Analysis**: History repeats; traders examine past trends to predict future ones
- **Subjectivity**: Even textbook technical analysis requires personal interpretation of patterns
- **Economic Indicators**: Employment rates, trade agreements, GDP trends
- **Currency/Asset Correlation**: Strong economy attracts foreign investment, driving up asset prices
- **Example**: US dollar dropping in 2007-2008 vs Canadian dollar rising — fundamental analysis captured this, technical analysis would have missed it

## Anti-patterns
- Forcing patterns onto charts where none exist (seeing what you want to see)
- Using only technical analysis for long-term macro trades
- Letting early technical analysis wins create overconfidence
- Believing technical analysis is purely objective — interpretation varies by trader

## Key Takeaways
- Technical analysis = short-term, pattern-based, builds confidence
- Fundamental analysis = long-term, economics-based, builds sustainability
- Start with technical analysis, graduate to fundamental analysis
- Both methods together outperform either alone
- Quick wins from technical analysis build momentum for beginners
