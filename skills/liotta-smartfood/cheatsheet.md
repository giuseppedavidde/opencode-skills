## Fasting-Mimicking: Allowed vs Excluded
| Category | ✅ Allowed | ❌ Excluded |
|----------|-----------|-------------|
| Vegetables | Non-starchy (leafy greens, cruciferous, peppers, zucchini) | Potatoes, starchy veg |
| Fats | EVOO, cold-pressed seed oils | Butter, margarine, lard |
| Seeds | 1 tbsp oil seeds | Legumes, nuts |
| Protein | None | Meat, fish, eggs, dairy, legumes, nuts |
| Carbs | None | Pasta, rice, bread, grains, fruit, sugar |
| Flavor | Herbs, spices, lemon | Honey, syrups, sweet sauces |

## Daily Smartfood Checklist
- [ ] ≥1 Longevity Smartfood per meal
- [ ] Vegetables covering ½ of each plate
- [ ] Whole grains at least once
- [ ] 30g nuts daily
- [ ] Legumes 3x/week
- [ ] Breakfast eaten
- [ ] Curcuma + pepe if cooking with curcuma
- [ ] Lemon/vit C with green veg for iron
- [ ] 25-30g fiber total
- [ ] Last meal ≥3h before sleep
