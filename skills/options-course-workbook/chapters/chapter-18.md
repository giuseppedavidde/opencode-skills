# Chapter 18: Tools of the Trade

## Core Idea
Tools flatten the learning curve but **too many create analysis paralysis**. Master a few strategies and the tools that support them rather than trying every available option.

## Frameworks Introduced
- **Essential Tool Categories**: Charts (line, bar, candlestick), software (Optionetics Platinum, ProfitSource, eSignal), seminars, web sites
- **Chart Types**: Line = close only (simple). Bar = OHLC (more detail). Candlestick = body + shadows (most visual detail for patterns)
- **Optionetics Platinum Key Features**: Stock/option search, risk graphs, IV rankings, back-testing (2.5+ years), trade portfolio tracking, Greeks for entire positions, paper trading

## Key Concepts
- The Optionetics web site provides free articles, quotes, option chains, broker reviews, and discussion boards
- New traders should **not** try to learn every strategy — specialize in 2–3
- Implied volatility charts, option skew charts, and IV/SV comparisons are critical for trade selection
- Stock ranking tools (35+ criteria) help screen for opportunities
- Trade probability of profit and expected profit are computed daily
- Back-testing at any historical date within 2.5 years validates strategy performance

## Key Takeaways
1. CBOE options calculator is a free essential tool for understanding pricing and Greeks
2. **Specialize**, don't generalize — mastery of 2–3 strategies beats superficial knowledge of 20
3. Combine free resources (Optionetics.com, CBOE) with paid tools (Platinum) for edge
4. Risk graphs should be viewed **before entering every trade**, regardless of tool used
