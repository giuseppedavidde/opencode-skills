# Chapter 3: Option Basics

## Core Idea
Every option has two sides: **the buyer has rights, the seller has obligations**. Each stock option controls 100 shares. Master the vocabulary of moneyness, expiration, premium, and strike prices before trading.

## Frameworks Introduced
- **Call vs Put**: Call = right to buy (bullish). Put = right to sell (bearish)
- **Moneyness**:
  - In-the-money (ITM): Call when underlying > strike; Put when underlying < strike
  - At-the-money (ATM): Underlying = strike (delta ~50)
  - Out-of-the-money (OTM): Call when underlying < strike; Put when underlying > strike
- **Three Resolutions of a Contract**: Expire worthless, be exercised, be assigned
- **American vs European Exercise**: American = exercise any time before expiration. European = exercise only on expiration date

## Key Concepts
- **Premium**: Determined by 7 factors: underlying price, option type, strike vs market (intrinsic value), time to expiration (time value), interest rate, volatility, dividends
- **Intrinsic Value**: Call = underlying − strike; Put = strike − underlying. OTM options have zero intrinsic value
- **Option Symbol Components**: Root symbol + expiration month (A-L for calls, M-X for puts) + strike price (letter code)
- **Option Class vs Series**: Class = all options of same type on same underlying. Series = same class with same strike, expiration, unit of trade

## Key Takeaways
1. Buyers have **defined risk** (premium only); sellers can have **unlimited risk** (no naked selling)
2. More time until expiration = more expensive premium (time value)
3. Strike prices come in increments: $2.50 for stocks <$25, $5 for stocks >$25
4. Expiration = Saturday after the 3rd Friday of the month; last trading day is the 3rd Friday
